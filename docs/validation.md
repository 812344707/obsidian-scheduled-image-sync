# 验证记录

版本：`1.0.10-local.4`。验证日期：2026-09-05。

## 自动化验证

`npm run typecheck` 通过；`npm test` 的 34 项测试全部通过。使用模拟 Obsidian API，以及绑定 `127.0.0.1` 的本机 HTTP 服务，不连接真实图床。OSS 请求通过纯内存拦截器捕获，不发往阿里云。

- 设置保存恢复、扫描间隔、关闭与卸载、移动端定时限制。
- 原位替换、保留原图、代码示例保护、普通链接保持、目录与静默期过滤。
- 上传失败、写回冲突与并发扫描；本机 HTTP 上传和图片内容读取。
- Markdown、Wiki、HTML、YAML、Canvas、引用式图片及代码中的引用保留；未保存编辑内容、元数据解析和双重 URL 编码保护。
- 只删除勾选项；缺少记录或图床配置变化时禁止远端删除；共享对象、图床链接仍被引用时保留远端对象。
- 检索后文件内容变化、文档读取失败、新增引用及新增上传记录会阻止相应删除。
- 图床 403、网络错误、重定向、服务错误不会视为删除成功；404 可视为已不存在。局部成功分别报告。
- 本地清理后保留上传记录，可在后续检索清理已无本地文件的远端对象。
- 本机 HTTP 服务核对 DELETE 目标与请求认证头，云端确认后才处理本地文件。

新增 OSS 验证：

- PUT、连接 GET、DELETE 的域名、路径、编码和签名；与 AWS Smithy SignatureV4 组件逐一比较 Authorization，一致。
- 地域前缀归一化、自动端点、非法 Bucket/地域和点路径拒绝。
- OSS 定时上传 → 中文路径链接替换 → 配置重载 → 引用保护 → 移除引用后联合删除 → 墓碑记录重载。
- 原有 R2/S3/MinIO/自定义服务保持路径寻址；旧上传记录兼容，服务商切换禁止误删。
- 连接重定向失败；上传权限错误不重试，429/503 重试。

## 尚未验证与限制

- 真实 OSS、S3、R2、MinIO 账号与权限尚未验证。本机服务成功不代表云账号可用。
- 联合删除在实机界面验证至预览，远端实际删除使用本机 HTTP 自动化测试验证。
- 手机端未实机验证。
- 引用检查覆盖当前库的 Markdown、Canvas、Bases、HTML；不涵盖其他库、外部网站、隐藏配置目录或未支持的二进制文档。
- 文字提及、同名歧义及代码示例采用保留策略，可能保留实际未使用的图片。
- 图床删除需持久上传记录，不根据旧日志或文件名推测对象；云端恢复取决于服务商版本控制与备份。
